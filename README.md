# 🔎 Virtual Escape Room — The Disappearance of Mr. White

A story-driven Python escape room game created as a capstone project for the **Statistics Bootcamp with Python: Zero to Mastery**.

## 🎮 About the Project

You play as a detective investigating the mysterious disappearance of wealthy businessman **Mr. White**.

Players must solve a series of randomized puzzles and uncover clues before the **5-minute timer** expires.

The puzzles include:

- 🔎 Riddles
- 🔐 Code-breaking challenges
- 🧩 Pattern-recognition puzzles
- 🕵️ Mystery clues

Incorrect answers deduct time from the clock, while correct answers reveal evidence about Mr. White's disappearance.

## 🐍 Python Concepts Used

This project combines several core Python concepts:

- Functions
- Lists
- Dictionaries
- For loops
- While loops
- If/else conditions
- User input
- Randomization
- Time tracking
- State tracking
- Answer validation

## ⚙️ Game Features

- 5-minute game timer
- Randomized puzzle order
- Multiple puzzle types
- 15-second penalty for incorrect answers
- Unlimited retries while time remains
- Story progression through discovered clues
- Win and loss conditions
- Case completion tracking

## 🏆 Objective

Solve every puzzle before time expires and uncover the truth behind **The Disappearance of Mr. White**.
